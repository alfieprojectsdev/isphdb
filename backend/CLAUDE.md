# backend/

Python prober daemon, systemd/launchd service units, and SQLite database.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `prober.py` | Infinite-loop daemon: ping + TCP fallback, periodic traceroute-hop capture, WAL writes, anomaly detection, graceful shutdown | Modifying probe logic, hop capture, alerting thresholds, DB writes, startup/shutdown |
| `test_prober.py` | stdlib unittest cases for `parse_ping_time`, `parse_traceroute_hops`, `is_mappable_hop` | Adding prober tests, verifying ping/traceroute parse logic |
| `geo_seed.py` | Dev-only, standalone script to refresh `frontend/src/lib/hop-geo.json` from a public geo API using captured hop IPs. The daemon never imports or calls it | Regenerating the curated hop-geo table when the route changes |
| `pyproject.toml` | uv project config; requires-python pinned to 3.12 | Changing Python version, adding dependencies |
| `uv.lock` | Locked dependency versions generated by uv | Never edit directly |
| `isp-health.service` | systemd user unit for the prober (WantedBy=default.target, no root) | Installing or modifying the Linux prober service |
| `com.user.isphealth.plist` | macOS launchd plist for the prober | Installing or modifying the macOS prober service |
| `network_metrics.db` | SQLite runtime database (WAL mode) | Inspecting stored data; never edit directly |
| `prober.log` | stdout log written by the systemd service | Debugging prober runtime output |
| `prober.error.log` | stderr log written by the systemd service | Debugging prober error output |

## Test

```bash
cd backend
python -m unittest test_prober.py
```

## Run

```bash
cd backend
uv run prober.py
```
